# Nerdverso

Um quiz de adivinhações sobre cultura nerd. Escolha uma categoria e tente acertar com o menor número de pistas para ganhar mais pontos.

## Categorias

Anime, música, séries, filmes, mangá e games.

## Jogar

Acesse a página publicada no GitHub Pages ou abra `index.html` em um navegador. O jogo também pode ser instalado como app pela opção de instalação do navegador e funciona offline depois do primeiro acesso.

## APK

O APK Android é compilado pelo GitHub Actions e publicado na página de Releases do repositório.
